# 加密貨幣是詐騙嗎？

從貨幣歷史，了解比特幣，看穿騙局 · 2026.10.23 分享會簡報

線上版：https://elijah-work.github.io/crypto-talk/ （推送到 `main` 後約 1 分鐘自動更新）

## 操作

- 電腦：← → 或空白鍵換頁，N 打開／關閉講稿，F 全螢幕，Home / End 跳到第一頁／最後一頁
- 手機：點畫面左側上一頁、右側下一頁，也可以左右滑動；長按畫面打開／關閉講稿（建議橫向觀看）

## 講稿

按「講稿」打開下方面板，可以「編輯 / 儲存 / 刪除 / 還原原稿」。
講稿存在這台裝置的瀏覽器裡；用「匯出講稿」下載 `notes.json`，放到這個 repo 的根目錄後，所有裝置打開都會看到同一份講稿。
